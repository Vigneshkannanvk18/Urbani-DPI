# DPI 2 go-live matrix

One table for all 14 items. "Built" means code, tests and docs exist on branch `dpi2`. "Verified" says what was actually exercised. Nothing has been deployed or run against AWS; every AWS-facing item is authored and checked offline only (CDK offline check, mocked SDKs, DynamoDB Local, local Docker).

Env variables live in `deploy/dpi2.env` (see `deploy/dpi2.env.example`, kept consistent with the backend by `npm run check:deploy`). Secrets are Secrets Manager names, never values. The owner column is a proposal: **U** = Urbani (client), **A** = AWS team, **D** = development team.
