## Deviations from the brief (decisions for the reviewer)
1. **Separate ECR repos** (`urbaniqa/dpi2-backend`, `urbaniqa/dpi2-frontend`) instead of reusing DPI 1's: DPI 1's initial deploy uses `:latest`, so pushing `latest` from DPI 2 into the same repo could change what DPI 1 pulls on a task restart. Configurable via `BACKEND_REPO`/`FRONTEND_REPO`; the guard refuses DPI 1's repos.
2. The table is created by `aws dynamodb create-table` in the script, because `cli.js tables` deliberately refuses AWS endpoints (item 1 guard). The bootstrap task runs only `seed.js --allow-aws` with `FORCE_DB_SEED=yes`. That seed also loads MOCK-labelled demo rows (there is no admin-only seed mode); not changed.
3. Route 53 record is opt-in and double-confirmed. Container Insights is opt-in with a warning.
